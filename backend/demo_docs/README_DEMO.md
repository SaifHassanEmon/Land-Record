# বাংলাদেশ ভূমি রেকর্ড ডেমো ডকুমেন্ট (Bangladesh Land Record Demo Documents)

এই ডিরেক্টরিতে গণপ্রজাতন্ত্রী বাংলাদেশ সরকারের ভূমি মন্ত্রণালয় (Ministry of Land) এবং ভূমি রেকর্ড ও জরিপ অধিদপ্তরের প্রচলিত ভূমি রেকর্ড সংক্রান্ত ৩টি প্রামাণ্য ডেমো পিডিএফ (PDF) ডকুমেন্ট অন্তর্ভুক্ত রয়েছে।

## ২. প্রতিটি দলিলের বিস্তারিত তথ্যাবলী (Detailed Field Specifications)

### ১) খতিয়ান (`khatian_demo.pdf`)
* **দলিলের ধরণ:** বি. এস. জরিপ (বাংলাদেশ সার্ভে - জমাবন্দি খতিয়ান)
* **খতিয়ান নং:** ৪৫৬
* **প্রশাসনিক এলাকা:**
  * জেলা: ঢাকা
  * উপজেলা: সাভার
  * ইউনিয়ন: আমিনবাজার
  * মৌজা: উত্তর সাভার (জে. এল. নং: ১৪২)
* **মালিকানার বিবরণ:**
  * মালিকের নাম: মোঃ আবদুল করিম
  * পিতার নাম: মোঃ রহিম উদ্দিন
  * মাতার নাম: মোসাঃ সালেহা বেগম
  * অত্র খতিয়ানের অংশ: ১.০০০ (সমগ্র অংশ)
* **দাগ ও জমির তফসিল:**
  * দাগ নং ১২৩ (কৃষি নাল জমি) — ০.৩৫ একর
  * দাগ নং ১২৪ (ভিটি জমি) — ০.২৫ একর
  * দাগ নং ১২৫ (বাগান) — ০.১৫ একর
  * **মোট জমির পরিমাণ:** ০.৭৫ একর (পঁচাত্তর শতাংশ জমি)
* **সরকারি ভেরিফিকেশন:** সহকারী কমিশনার (ভূমি), সাভার এবং আমিনবাজার ইউনিয়ন ভূমি অফিসের সিল ও ডিজিটাল কিউআর কোড।

### ২) পর্চা / ভূমি কর রসিদ (`porcha_demo.pdf`)
* **দলিলের ধরণ:** ভূমি উন্নয়ন কর রসিদ (দাখিলা) ও পর্চা
* **বাংলাদেশ ফরম নং:** ১০৭৭
* **পর্চা নং:** ৭৮৯ | **হোল্ডিং নং:** ১৪৫
* **খতিয়ান রেফারেন্স:** আর এস খতিয়ান নং ৩২১ | বি এস খতিয়ান নং ৪৫৬
* **প্রশাসনিক এলাকা:**
  * জেলা: চট্টগ্রাম
  * উপজেলা: হাটহাজারী
  * ইউনিয়ন/পৌরসভা: মেখল
  * মৌজা: মেখল (জে. এল. নং: ৭২)
* **করদাতার বিবরণ:**
  * নাম: ফাতেমা বেগম
  * স্বামী/পিতা: মরহুম শামসুল হক
  * জাতীয় পরিচয়পত্র: ১৯৬৮১৫৯৭৫৩১২০০০০১
* **দাগ ও করের হিসাব:**
  * দাগ নং ২৫৬ (নাল জমি - ২০ শতাংশ): কর ২০০/- টাকা
  * দাগ নং ২৫৭ (ভিটি জমি - ১৫ শতাংশ): কর ৩৫০/- টাকা
  * **সর্বমোট জমি:** ৩৫ শতাংশ (০.৩৫ একর)
  * **মোট আদায়কৃত ভূমি কর:** ৫৫০/- টাকা (পাঁচশত পঞ্চাশ টাকা মাত্র)
* **পেমেন্ট তথ্য:** অনলাইন ই-পেমেন্ট গেটওয়ে, ট্রানজেকশন আইডি: TXN-8923741029, ইস্যু তারিখ: ০১ সেপ্টেম্বর ২০২৪।

### ৩) বায়না ও বিক্রয় দলিল (`deed_demo.pdf`)
* **দলিলের ধরণ:** সাফ-কবলা বিক্রয় দলিল (বায়না ও চূড়ান্ত দলিল)
* **দলিল নং:** ১১২৩ / ২০২৪
* **সাব-রেজিস্ট্রি অফিস:** মিরপুর, ঢাকা
* **নিবন্ধন তারিখ:** ২০ আগস্ট ২০২৪
* **স্ট্যাম্প তথ্য:** বাংলাদেশ সরকারের ১০০০/- টাকা মূল্যের নন-জুডিশিয়াল স্ট্যাম্প রেপ্লিকা (ক্রমিক নং: খগ-৭৮৬৪৫২১)
* **পক্ষগণের পরিচয়:**
  * **১ম পক্ষ (বিক্রেতা / দাতা):** মোঃ জাহাঙ্গীর আলম, পিতা: মরহুম রফিকুল ইসলাম, সাং: মিরপুর-১০, ঢাকা।
  * **২য় পক্ষ (ক্রেতা / গ্রহীতা):** নাসরিন সুলতানা, পিতা: সুলতান মাহমুদ, সাং: উত্তরা মডেল টাউন, ঢাকা।
* **জমির বিবরণ ও অবস্থান:**
  * ঢাকা জেলার, মিরপুর উপজেলার, পীরেরবাগ মৌজার দাগ নং ৩৩৪ এর ০.২৫ শতাংশ জমি।
  * খতিয়ান নং: ৮৯ | আর. এস. দাগ নং: ৭৬২ | জমির শ্রেণী: বাস্তু / নাল
  * বিক্রিত জমির পরিমাণ: ০.২৫ শতাংশ (পঁচিশ অযুতাংশ)
* **পণমূল্য (বিক্রয় মূল্য):** ৩৫,০০,০০০/- টাকা (পঁয়ত্রিশ লক্ষ টাকা মাত্র)
* **পরিশোধ মাধ্যম:** সোনালী ব্যাংক পিএলসি, মিরপুর শাখা কর্তৃক ইস্যুকৃত পে-অর্ডার (PO-459201)।
* **স্বাক্ষর ও সাক্ষ্য:** বিক্রেতা ও ক্রেতার স্বাক্ষর, সনাক্তকারী আইনজীবী (এডভোকেট আতিকুর রহমান), দুই জন সাক্ষী এবং সাব-রেজিস্ট্রারের সিল।

## ৩. ফাইল তৈরির স্ক্রিপ্ট চালনা (How to Run the Script)

প্রয়োজনীয় লাইব্রেরি ইনস্টল করুন (যদি ইতিপূর্বে ইনস্টল না থাকে):
```bash
pip install reportlab
```

স্ক্রিপ্টটি রান করতে টার্মিনাল বা কমান্ড প্রম্পটে চালান:
```bash
python backend/generate_demo_docs.py
```

### ফন্ট ম্যানেজমেন্ট (Font Handling)
স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে Google Fonts থেকে `HindSiliguri-Regular.ttf` এবং `HindSiliguri-Bold.ttf` ডাউনলোড করে এই ফোল্ডারে সেভ করে নেয়। ফলে বাংলা যুক্তাক্ষর এবং ইউনিকোড টেক্সট কোনো সমস্যা ব্যতিরেকে নিখুঁতভাবে রেন্ডার হয়।
ইন্টারনেট সংযোগ না থাকলে এটি স্বয়ংক্রিয়ভাবে উইন্ডোজ সিস্টেমের বাংলা ফন্ট (Nirmala UI / Vrinda) ব্যবহার করার ব্যাকআপ ব্যবস্থা ধারণ করে।
